# Asset Integrity And Reliability Analysis

## Overview

This project summarizes asset integrity and reliability engineering work connected to industrial equipment, maintenance planning, risk assessment, and engineering data analysis.

## Engineering Problem

Industrial assets need structured maintenance and integrity programs to reduce downtime, manage risk, and support safe operation. Engineering analysis helps connect inspection records, failure modes, standards, and maintenance decisions.

## Methods

- Prepared asset registers and equipment documentation
- Developed FMECA and reliability-centered maintenance inputs
- Reviewed inspection and maintenance records
- Supported remaining life and fitness-for-service style assessments
- Created risk matrices, maintenance recommendations, and client-facing deliverables

## Tools And Standards

- Excel
- Python where applicable
- API 571 / API 579 familiarity
- ASME B31.3 familiarity
- ISO 14224 and OREDA-informed reliability practices
